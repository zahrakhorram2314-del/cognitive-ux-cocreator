## 📌 Overview

Most digital products don't fail due to poor code; they fail because they ignore **human psychology and cognitive friction**. 

**Cognitive UX Co-Creator** is an experimental AI Agent built in Google AI Studio. It acts as a dedicated UX Research assistant, analyzing product flows, identifying mental friction points, and proposing evidence-based psychological reframing.

---

## 🚀 Key Features & Perspective Reframing

The agent evaluates target user flows through multiple psychological lenses:
- 🕵️‍♀️ **UX Researcher Mode:** Deep-dive into extraneous cognitive load, decision friction, and mental model mismatches.
- 🤝 **Best Friend Mode:** Empathetic, human-centered evaluation focusing on emotional friction and psychological safety.
- ⏳ **10 Years Later:** Assessing long-term usability patterns, scalability, and sustainable interaction design.
- 📊 **Objective / Evidence:** Scientific analysis rooted in Human-Computer Interaction (HCI) frameworks.

---

## 🔎 Sample Analysis: Event Registration Pass Selection

Below is a real-world audit generated by the agent for a generic registration flow:

### 1. Identified Issues (What I see)
- **Fragmented pass selection:** Assistant/caregiver passes hidden in deep menus or accessibility FAQs.
- **Ambiguous price/policy signals:** Lack of upfront clarity on assistant document verification requirements.
- **Redundant data entry:** Forcing attendees to repeat billing and demographic information twice.

### 2. Psychological Impact (Cognitive Impact)
- **Extraneous Cognitive Load:** Forcing users to split visual attention across disparate tables and policy documents.
- **Decision Hesitation:** High cognitive load leads to form drop-offs and user anxiety.

## 🛠️ How to Deploy & Use in Google AI Studio

1. Open [Google AI Studio] https://ai.studio/apps/9cf51f91-5212-4b4b-9ba2-ca55d9b37569
2. Create a new **System Instruction / Prompt**.
3. Copy the instructions from [`system_instructions.md`](./system_instructions.md) in this repository.
4. Input your target UX scenario, user needs, and framework focus.
5. Review the structured output generated by Gemini!
